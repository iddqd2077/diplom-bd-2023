# Дипломный проект по базе данных

Это мой дипломный проект 2023 года, сделанный как десктопное приложение для работы с базой данных.

## О проекте

Приложение написано на Python с использованием PyQt5 и SQLite. Оно представляет собой менеджер для ведения учёта клиентов, сотрудников, заказов, чеков, склада, техники и услуг.

В проекте есть отдельные окна для:

- клиентов;
- заказов;
- чеков;
- техники;
- сотрудников;
- услуг;
- склада;
- календаря;
- отчётов;
- погоды.

Также в программе есть экспорт данных, формирование Word-отчётов и работа с таблицей базы данных.

## Технологии

- Python
- PyQt5
- SQLite
- python-docx
- openpyxl
- matplotlib

## Запуск

1. Установите зависимости:

```bash
pip install pyqt5 python-docx openpyxl matplotlib
```

2. Запустите приложение:

```bash
python main.py
```

## Файлы проекта

- main.py — главное окно приложения.
- DataBase.db — база данных проекта.
- остальные .py файлы — отдельные окна и функции для работы с данными.
